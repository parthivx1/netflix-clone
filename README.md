# Netflix Clone

A responsive clone of the Netflix India landing page built using HTML and CSS.

## Features

- Netflix-inspired landing page design
- Navigation bar with language and sign-in buttons
- Email signup section
- Feature showcase sections
- TV and device video previews
- Frequently Asked Questions (FAQ) section
- Responsive layout for desktop, tablet, and mobile devices
- Custom typography using Google Fonts
- Favicon support

## Tech Stack

- HTML5
- CSS3

## Preview

This project recreates the look and feel of the Netflix India homepage while focusing on responsive layouts, modern CSS styling, and clean UI design.
